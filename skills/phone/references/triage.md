# 分流对照：这事在网页办还是在手机 App 办

原则：能在网页/联网工具拿到的，就不开手机；只有「我的数据」「要定位或登录态」「网页版阉割」三种情况上手机。
两边都行先网页，网页不行再手机，并告诉用户一句。

## 常见需求 → 去哪办

| 需求 | 先试 | 不行再 | 为什么 |
|---|---|---|---|
| 天气、空气、限行 | web_search | — | 公开数据 |
| 新闻、常识、翻译、润色 | 直接答 / web_search | — | 不需要设备 |
| 某家店营业时间、地址、电话 | web_search（高德/点评网页） | 手机·大众点评 / 美团 | 网页通常有，但评分和最新评价 App 更全 |
| 附近有什么吃的、按距离排 | 手机·美团 / 大众点评 | — | 要定位 |
| 外卖能不能送、配送费、预计时间 | 手机·美团 | — | 要定位 + 登录态 |
| 团购券价格、套餐内容 | web_search 粗看 | 手机·美团 / 大众点评 | 券价常有 App 专享 |
| 小红书上怎么评价某店/某物 | 手机·小红书 | — | 网页版看不到正文 |
| 抖音上的探店/视频 | 手机·抖音 | — | 网页版阉割 |
| 某商品多少钱、参数 | web_search（京东/淘宝网页） | 手机·淘宝 / 京东 | 网页能看公开价；券后价、会员价要 App |
| 我买过什么、物流到哪了 | 手机·淘宝 / 京东 / 菜鸟 | — | 我的订单 |
| 快递单号查进度 | web_search（快递100等） | 手机·菜鸟 / 支付宝 | 公开单号网页可查；不知道单号只能看 App |
| 闲鱼有没有二手、多少钱 | 手机·闲鱼 | — | 网页版几乎不可用 |
| 支付宝账单、花呗还款日、会员码 | 手机·支付宝 | — | 我的数据；只看，不操作 |
| 两地怎么走、要多久 | web_search（高德/百度地图网页） | 手机·高德地图 | 实时路况和公交到站 App 更准 |
| 打车大概多少钱 | 手机·滴滴（只看预估，不叫车） | — | 要定位 + 登录态 |
| 机票/火车票价格、余票 | web_search（12306、携程网页） | 手机·飞猪 / 携程 | 公开可查 |
| 我的机票/酒店订单 | 手机·飞猪 / 携程 | — | 我的订单 |
| 电影排片、票价 | web_search（猫眼/淘票票网页） | 手机·淘票票 | 公开可查；选座要 App |
| 微信里某人说过什么、群里的通知、公众号文章 | 手机·微信（只看） | — | 我的数据；绝不发消息 |
| 发消息、发朋友圈、转账、加好友 | 不做 | 不做 | 超出边界，让用户自己来 |

## 判断信号速查

上手机的信号：「我的」「最近买的」「物流」「账单」「附近」「最近的」「送到」「优惠券」「拼团」「笔记」「评论区」「闲鱼」「抖音」。
不用上手机的信号：「大概」「一般」「通常」「是什么」「怎么做」「翻译」「天气」「新闻」「几点开门」（先网页）。

## 两条例外

-用户明说「用手机看」「App 里查」→ 直接上手机，不再分流。
- 网页查到的结果和他的描述对不上（比如他说那家店搬了）→ 上手机核一遍。
