# 京东

## 能在这里查到/办到什么
- 订单：我的 → 待付款 / 待收货 / 退换售后 / 全部订单，每单的商品名、实付金额、下单时间、状态
- 物流：京东物流的轨迹细到「配送员正在派送」、预计送达时间段；第三方商家走其他快递
- 售后进度：退货、换货、维修的处理状态，退款金额和退回去向
- 价格保护：订单里能看到是否降价、可申请价保的差价金额（只看）
- 商品：京东价、到手价、PLUS 价、国补价；自营还是第三方；按用户收货地址显示的有货/无货和预计送达；评价、问大家
- 购物车、关注的商品（收藏）、足迹，以及降价提示
- 京豆、优惠券、PLUS 会员权益
- 京东秒送、京东外卖：附近门店即时配送，需要定位

## 分流：网页能不能替代
- 优先网页：
  - 商品参数和大致价格：jd.com 商品页一般不登录也能看，但到手价、券后价、国补价可能和 App 不一样
  - 历史价格走势：比价网站
  - 已知京东物流运单号：京东物流官网可查
- 必须上手机：
  - 订单、物流、售后、价保、京豆、优惠券：依赖登录态；需要检查当前设备的登录态
  - 「送到我这儿要多久」「有没有货」：取决于账户里的收货地址
  - App 专享价、PLUS 价、国补资格：以 App 为准
  - jd.com 搜索近年常要求登录，未登录搜索结果不稳定
- 一句话判断：问「京东卖多少、明天能不能到」或任何「我的订单」→ 手机；只问参数 → 网页

## 入口与路径
- 底部 Tab 大致是：首页、秒送或外卖类 Tab、内容类 Tab、购物车、我的；「我的」在最右（名称和顺序以真机为准）
- 首页顶部是搜索框，框内有拍照购相机图标；搜索框附近有频道（首页、秒送、外卖、超市、国补等）
- 订单：我的 → 订单区的待付款 / 待收货 / 退换售后，旁边「全部订单」
- 物流：待收货 → 点订单进详情，顶部就是最新物流摘要，点开看完整轨迹
- 价保：订单详情或订单卡片的按钮里有价格保护入口
- 搜索结果：综合 / 销量 / 价格 / 筛选（可勾京东物流、自营、价格区间）
- 商品详情：首屏图片，往下价格与优惠、「已选」规格行、「送至」地址和预计送达，评价在更下方或顶部「评价」Tab

## 常见弹窗与坑
- 开屏广告；首页红包、优惠券、会员弹窗；618 是京东主场，大促期弹窗特别多
- 定位、通知权限弹窗：秒送和外卖需要定位，其余拒绝
- 价格层级多：京东价、券后到手价、PLUS 价、国补后价、百亿补贴价 → 任务里要求执行器注明是哪一种
- 自营和第三方店铺同款混排，标「自营」的才是京东自营；搜索结果有广告位
- 商品页「送至」地址决定有没有货和送达时间，执行器不能改它
- 订单详情页底部按钮多（确认收货、申请售后、再次购买、评价），容易误触
- 首页和「我的」里有白条、金条、京东金融入口和浮动红包，误点会进金融页面
- 京东物流包裹在菜鸟里经常不全，京东的件就在京东查

## 敏感动作清单（执行器必须停下、小满必须先问用户的）
- 立即购买、加入购物车、去结算、提交订单、付款
- 确认收货、申请售后或退换、取消订单、删除订单
- 申请价保（虽然只是退差价，也先问）
- 联系客服或商家（发消息）、评价晒单
- 修改收货地址、切换「送至」地址
- 白条、金条、京东金融的任何页面，开通或续费 PLUS
- 领券、签到领京豆、用京豆抵扣
- 关注或取关商品、店铺

## 任务描述模板
（任务开头写「打开京东」，执行器靠任务里的 App 名加载京东专属经验）
- 打开京东，进入我的→待收货，用 finish 汇报每个订单的商品名、预计送达时间和最新物流状态。不要确认收货。
- 打开京东，搜索「XX」，筛选自营，用 finish 汇报前 5 个商品的标题、页面价格（注明是京东价还是到手价）、是否有货和预计送达时间。不要加入购物车，不要购买。
- 打开京东，进入我的→全部订单，找到「XX」的订单，打开价格保护页面，用 finish 汇报能否价保和可退差价金额。不要点申请价保。
- 打开京东，进入我的→退换售后，用 finish 汇报每条售后的商品名、处理状态和退款金额。不要取消售后。
- 打开京东，进入购物车，用 finish 汇报每件商品的名称、现价和有没有降价提示。不要结算或删除。

## 待实测校准
- 底部 Tab 的现名和顺序（秒送、外卖入口在 Tab 栏还是首页频道里）
- 价保入口的准确位置和名称（订单详情内，还是我的 → 客户服务）
- 「我的」页订单区按钮的文字（退换/售后的写法）
- 商品详情页预计送达的显示位置和措辞
- 搜索结果「自营」筛选的位置
- 首页、「我的」页金融入口的位置，避免误点
