# 携程

## 能在这里查到/办到什么
- 机票：单程/往返/多程；航班列表（起降时间、航站楼、航司、机型、准点率）；前后几天价格条、低价日历；点进单个航班看多种价格产品（航司旗舰店、特价、商务优选等，各自的退改和行李额）
- 航班动态：按航班号或起降城市查计划/预计起降时间、延误、航站楼、登机口
- 酒店：列表价、评分、点评数（携程点评量大，适合看口碑）、位置距离；详情页房型价、是否含早、取消政策、会员价
- 火车票：车次、余票、各席别价格，以及抢票/候补入口（只看）
- 门票·玩乐：景点门票价、预约须知、开放时间；用车：接送机、租车估价
-用户自己的：全部订单（待付款 / 待出行 / 退款）、「行程」里即将出行的航班/酒店/火车、会员等级与积分、优惠券

## 分流：网页能不能替代
- 优先网页：携程网页版的机票、酒店、火车票频道功能比较全，不登录也能查航班列表、酒店大概价位、火车余票；景点开放时间、门票价也可以先搜网页。只要一个大概价、不涉及用户账号时，先走网页。
- 网页靠不住再上手机：网页常弹滑块验证、列表是动态渲染抓不到；App 有「App 专享价」/会员价，和网页价可能不同。用户要的是「现在在携程订实际多少钱」时上手机。
- 必须上手机：
  -用户的订单、行程、退改进度、会员积分、优惠券——账号数据
  - 和飞猪比价——两个 App 各查一次，同日期同舱位同房型对比
- 火车余票以 12306 为准，携程只是代购渠道；单纯查余票优先 12306 网页。

## 入口与路径
- 首页：顶部搜索框（搜目的地、酒店名、景点、航班号）；下面是业务入口宫格，酒店、机票、火车票、旅游通常是第一排大入口，门票·活动、用车、民宿、汽车票等在后面或「更多」；再往下是推荐内容流。底部 Tab 一般有首页、行程、我的等；页面上可能有 AI 助手悬浮按钮。
- 机票：首页「机票」→ 单程/往返 → 出发/到达城市 → 日期 → 舱位、乘客类型 →「查询」/「搜索」→ 航班列表。顶部价格条横滑换日期；筛选（直飞、时段、航司、机场）与排序（低价、时间）在列表底部或顶部条；点航班进入价格产品列表，各产品下有退改签说明。
- 航班动态：机票频道里的「航班动态」，或首页搜索框直接输航班号（入口待实测）。
- 酒店：首页「酒店」→ 国内 / 海外 / 民宿 / 钟点房 → 目的地或位置、入住离店、房间人数、关键词 →「查询」→ 列表。顶部有排序（欢迎度 / 好评 / 低价 / 距离）、位置、价格星级、筛选；详情页上滑看房型。
- 火车票：首页「火车票」→ 出发站/到达站 → 日期 → 只看高铁动车 → 查询 → 车次列表。
- 订单：「我的」→ 全部订单；即将出行的也在「行程」Tab。

## 常见弹窗与坑
- 开屏广告；首页新客礼包、领券、会员升级弹窗；红包或活动悬浮球挡住按钮；首次启动隐私协议、定位和通知权限。
- 登录失效：查订单、看会员价时跳登录 → Take_over；连续快速操作可能弹滑块验证 → Take_over。
- 机场：北京首都 PEK / 大兴 PKX，上海虹桥 / 浦东，列表里要看清；用户只要某个机场时写明。
- 默认排序不一定是低价，最便宜的不在第一条；要切「低价」排序或往下滑对比。
- 列表价不等于实付：「起」价、会员价、领券后价；国内机票列表价是否含机建燃油、国际是否含税，以页面说明为准（待实测）；最低价产品常限制退改、要求加购，或只限特定乘客（学生、老人、新客）。
- 酒店列表价常是券后价/会员价，有的不含税费；以详情页房型价为准，并看是「免费取消」还是「不可取消」。
- 火车票结果页、机票填单页会推抢票加速包、保险、贵宾厅、接送机等加购项。
- 日历跨月需上滑；往返要先选去程日再选返程日；顶部价格条一碰就换日期。

## 敏感动作清单（执行器必须停下、小满必须先问用户的）
- 预订、提交订单、去支付、确认支付；开通信用支付/先享后付
- 抢票、候补、购买加速包
- 退票、改签、退订、取消订单、申请退款、修改订单
- 在线值机、选座
- 新增 / 修改常用旅客、证件、联系人
- 联系客服、给酒店或商家留言、在线咨询（等于发消息）；发表点评、问答
- 领券、开通会员、购买权益卡（可能扣费或带条件）
- 设置低价提醒、分享行程

## 任务描述模板
任务里写「携程」，执行器才会加载携程专属经验。日期写全，城市写清楚，有指定机场写机场。
- 打开携程，查 10月25日 北京到深圳的单程经济舱机票，切换到低价优先排序，用 finish 汇报最便宜的 3 个航班：航班号、起降时间和机场、价格、页面上写的税费说明。不要预订。
- 打开携程，查航班号「XX1234」10月9日的航班动态，用 finish 汇报计划和预计起降时间、航站楼、登机口和当前状态。只看。
- 打开携程，搜 10月25日入住、27日离店、深圳南山科技园附近的酒店，按好评排序，用 finish 汇报前 3 家的名称、评分、点评数和列表价；再点进第一家，汇报最便宜房型的价格、是否含早和取消政策。不要预订。
- 打开携程，进入「我的」→ 全部订单，用 finish 汇报待出行订单的类型、日期、行程内容和状态。只看，不要退改、不要联系客服。

## 待实测校准
- 底部 Tab 的实际名称和数量；AI 助手悬浮按钮的位置，会不会挡住操作
- 首页宫格布局，机票 / 酒店 / 火车票入口的位置
- 航班动态入口：机票频道里，还是首页搜索航班号就能进
- 机票列表的排序和筛选在顶部还是底部；默认排序是什么
- 国内机票列表价是否含机建燃油；国际机票含税开关的位置
- 酒店列表价「券后 / 会员」的标识方式，是否含税费
- 携程网页版不登录时的可用程度和验证频率（决定分流比例）
- 登录态有效期；「查列表 + 点进详情」实际要多少步
