# 菜鸟

## 能在这里查到/办到什么
- 我的包裹：按手机号自动汇总的包裹（淘宝、天猫为主，也有其他平台和快递公司的件），分待取件、运输中、派送中、已签收
- 取件码：放进驿站或快递柜的包裹的取件码、驿站或柜子名称、地址、营业时间
- 物流轨迹：每个包裹的快递公司、运单号、完整轨迹、预计送达
- 查件：输入运单号查任意快递
- 寄件：寄件价格估算、附近驿站（只看价，不下单）
- 身份码：驿站取件用的身份码（只在用户明确要去取件时才打开，见敏感清单）

## 分流：网页能不能替代
- 优先网页：
  - 已知运单号 → 快递100、快递公司官网或网页搜索单号即可，不上手机
  - 寄件价格的大致区间 → 网页
- 必须上手机：
  - 「我有哪些快递、到哪了」：包裹列表依赖手机号登录和授权
  - 取件码：只在菜鸟 App（或手机短信）里有，网页查不到
  - 驿站、快递柜的具体位置和营业时间：需要定位
- 京东物流的包裹在菜鸟里经常不全 → 京东的件直接查京东 App
- 一句话判断：问「有没有快递、取件码多少、所有快递到哪了」→ 首选菜鸟；问「淘宝某一单」→ 淘宝或菜鸟都行

## 入口与路径
- 执行器目前的 Launch 不认识「菜鸟」（它的应用表里没有），会退回桌面找图标，多耗几步
- 首页上方是搜索或查件框（可输入运单号），下面就是「我的包裹」列表或卡片
- 包裹列表顶部有状态 Tab：全部、待取件、运输中、派送中、已签收（名称以真机为准）
- 点包裹卡片 → 包裹详情：物流轨迹、快递公司、运单号；驿站件会显示取件码和驿站地址
- 底部 Tab 大致有首页（包裹）、寄件、我的

## 常见弹窗与坑
- 开屏广告、领红包或寄件优惠券弹窗、开启通知弹窗
- 定位权限弹窗：查附近驿站需要，查取件码不需要，可拒绝
- 首次可能弹「导入包裹」「授权淘宝账号」「授权手机号」一类提示 → 不要同意，先回来问用户
- 包裹列表里混着广告卡片和商品推荐，不是真包裹
- 取件码有时要点「查看取件码」或展开卡片才显示
- 包裹多时要往下滑；已签收的排在后面，可能折叠
- 派送中的包裹可能有「送货上门 / 放驿站」选择按钮，误触会改变派送方式
- 快递柜包裹可能有远程开柜一类按钮，绝不能点
- 身份码等于取件凭证，执行器截图会经微信发回来，任务没要求就不要打开

## 敏感动作清单（执行器必须停下、小满必须先问用户的）
- 寄快递下单、预约上门取件、付款
- 修改派送方式（送货上门、放驿站、放快递柜）、预约派送时间、改地址
- 远程开柜、确认签收、一键取件
- 打开身份码或取件二维码
- 授权导入包裹、绑定淘宝或支付宝账号、手机号授权
- 删除包裹、投诉、联系快递员或驿站（打电话、发消息）
- 领券、开通会员

## 任务描述模板
（任务开头写「打开菜鸟」，执行器靠任务里的 App 名加载菜鸟专属经验）
- 打开菜鸟，在我的包裹里切到待取件，用 finish 汇报每个包裹的取件码、驿站或快递柜名称和地址。不要点开柜、签收或改派送方式。
- 打开菜鸟，查看我的包裹里所有运输中和派送中的包裹，用 finish 汇报每个的快递公司、商品名（如有）和最新物流状态。只看不改。
- 打开菜鸟，在首页查件框输入运单号「XXXX」查询，用 finish 汇报快递公司和最新三条物流。不要寄件。
- 打开菜鸟，在我的包裹里找和「XX」有关的包裹，用 finish 汇报物流状态和预计送达时间。不要联系快递员。

## 待实测校准
- 首页布局：包裹列表直接在首页，还是在单独的 Tab 里
- 状态 Tab 的准确名称和顺序
- 取件码的显示方式（直接显示还是要点开）
- 底部 Tab 的组成
- 京东、拼多多的包裹在菜鸟里能看到多少
-用户的菜鸟是否已登录并授权手机号导入包裹
- 远程开柜、改派送方式等按钮在包裹详情里的位置
- 执行器应用表补上「菜鸟」后，删掉入口里那条 Launch 说明
