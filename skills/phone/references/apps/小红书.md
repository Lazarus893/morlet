# 小红书

## 能在这里查到/办到什么
- 搜索笔记：旅行攻略、探店、测评、避雷、教程、穿搭；能看标题、正文、图片（攻略常写在图片里）、点赞/收藏/评论数、发布时间、IP 属地。
- 评论区：高赞评论、楼中楼回复（真实体验和避雷常在评论里）。
- 作者主页：粉丝数、获赞与收藏、笔记列表。
- 地点相关笔记：餐厅、景点的笔记（附近、同城要定位）。
- 搜索结果里的问答/AI 总结类入口（9.49.1 版有没有、叫什么，待实测）。
- 市集商品：价格、销量、店铺。
- 「我」：用户自己收藏、赞过的笔记和专辑；消息页的评论、@、私信（只读，用户要求才看）。

## 分流：网页能不能替代
- 优先网页：用户直接发来笔记链接（xhslink 短链或 xiaohongshu.com 链接）时，先用网页抓取打开这一篇，正文和图片够用就不上手机。
- 必须上手机：
  - 搜索 + 筛选 + 翻多页：网页版搜索要登录、结果少、翻页受限、常被风控。
  - 完整评论区和楼中楼：网页版只显示一部分评论。
  -用户的收藏、赞过、消息：要登录态。
  - 附近/同城笔记：要定位。
- 视频笔记：执行器听不到语音，只能读标题、正文、画面字幕和评论。要结论就优先找图文笔记。

## 入口与路径
- 首页：顶部「关注 / 发现 / 城市名」三个 Tab，默认在「发现」双列瀑布流；右上角放大镜是搜索入口；底部 Tab 是首页、市集、+（发布）、消息、我。
- 搜索：右上角放大镜 → 搜索页 → 输入关键词 → 点下拉建议项进结果（比点「搜索」按钮稳）。
- 结果页：顶部有全部/用户/商品等分类 Tab；排序和筛选在结果页右上的「筛选」里（综合/最新/最多点赞、笔记类型图文/视频、发布时间等）。
- 笔记详情：上半是图片（左右滑翻页），下半是标题、正文、话题、发布时间和 IP 属地；再往下是评论区，「展开 N 条回复」要点开。
- 作者主页：在笔记详情顶部点作者头像或昵称。
- 收藏：底部「我」→「收藏」Tab（旁边还有「笔记」「赞过」）。

## 常见弹窗与坑
- 打开时常弹「开启通知」「青少年模式」「发现新版本」，关掉就行。
- 搜索结果夹着「赞助」「广告」笔记和直播卡片，要跳过。
- 双列瀑布流容易点错左右列；执行器点错会退回重试，耗步数。
- 攻略内容常在图片里，一篇九张图要逐张翻，步数消耗大。只要 3 篇就别要 10 篇；打开 3 篇以上的任务步数给到 40。
- 正文长要点「展开」；评论按热度排，要看最新评论得切换。
- 双击笔记图片会直接点赞，执行器不能双击。
- 发布时间常显示为「3 天前」「09-12」这种格式，今年的笔记可能不带年份；汇报时让执行器原样抄。
- 搜索结果是推荐算法排序，「综合」第一条不一定最热；要热度就让执行器按最多点赞排。

## 敏感动作清单（执行器必须停下、小满必须先问用户的）
- 点赞（包括双击图片）、收藏、取消收藏
- 评论、回复、@ 别人
- 关注/取关作者
- 私信、分享到微信或其他 App
- 发布笔记（底部「+」）、删除笔记或评论
- 市集下单、加购物车、支付
- 「不感兴趣」、举报（会改变用户的推荐）

## 任务描述模板
- 「打开小红书，搜索「成都 三天两晚 攻略」，在筛选里选图文、按最多点赞排序，依次打开前 3 篇，用 finish 汇报每篇的标题、点赞数和推荐的景点、餐厅名。不要点赞、收藏或评论。」
- 「打开小红书，搜索「XX 店 避雷」，打开最新的 3 篇笔记，看正文和前几条高赞评论，用 finish 汇报主要的好评和差评点。只看不互动。」
- 「打开小红书，点底部「我」→「收藏」，找到标题里带「露营」的笔记，用 finish 汇报标题、作者和正文要点。不要取消收藏。」
- 「打开小红书，搜索用户「XXX」，进入主页，用 finish 汇报粉丝数和最近 3 篇笔记的标题与发布时间。不要关注。」
