# 滴滴出行

## 能在这里查到/办到什么
- 打车估价：输好上车点和目的地后，车型选择页列出特惠快车、快车、拼车、出租车、专车、豪华车等各自的预估价；拼车常分「拼成 / 未拼成」两档；部分车型显示预计接驾时间
- 高峰与优惠信息：车型页可能出现「需求旺盛」「加价」「动态调价」「已优惠 X 元」「一口价」之类的标注
- 行程/订单记录：历史行程的日期、起终点、车型、实付金额、费用明细、车牌
- 进行中的行程：车牌、车型、司机预计到达时间、行程轨迹（前提是这单就是用这台手机叫的）
- 其他业务：代驾估价、顺风车、公交、青桔骑行、租车（一般用不上）
- 账户：优惠券、钱包余额、发票记录（只看）

## 分流：网页能不能替代
- 优先别的渠道：
  - 只想知道「打车大概多少钱」：高德地图的驾车路线或「打车」方式会给一个大致价格，网上也能查到北京快车计价规则粗算；精度要求不高就不用上滴滴
  - 两地距离、开车多久 → 高德地图（见高德参考）
- 必须上手机：
  - 滴滴各车型此刻的预估价、预计接驾时间、有没有加价——只有登录状态的 App 算得出，网页没有
  - Tony 的行程记录、花费、发票——账号数据
  - 进行中行程的车辆信息
- 上车点：默认是手机定位，也就是这台连着 Mac 的手机所在地。Tony 不在 Mac 旁边、或想从别处出发时，任务里一定写明上车点。

## 入口与路径
- 首页：上半部分是地图和当前定位；地图上方或卡片顶部有一排业务入口（打车/快车、专车、顺风车、代驾、公交、骑行等，可横滑），默认在打车；下方卡片里是「你要去哪儿」目的地输入框，上车点显示在它上面。「我的」入口在底部 Tab 或左上角头像（以实测为准）。
- 查估价：首页「你要去哪儿」→ 地址搜索页（上面是上车点、下面是目的地）→ 需要时先点上车点改成指定地点 → 输入目的地并从下拉建议里选 → 自动跳到车型选择页（估价页）→ 读各车型价格 → 停。
- 车型选择页：上半是地图路线，下半是车型列表（每行车型名 + 预估价 + 勾选框），有时要上滑列表才能看全；最底部是醒目的「确认呼叫」大按钮，附近可能有「预约」「帮人叫车」「支付方式」「优惠券」等小入口。
- 首页可能有「家」「公司」「最近去过」快捷卡片，点了会跳过输入直接到车型选择页（是否会直接呼叫待实测，确认前不要让执行器点）。
- 订单记录：「我的」或头像菜单 → 订单/行程 → 列表 → 点进单条看费用明细。
- 城市：地址搜索页左侧有城市切换，跨城（比如去天津、廊坊）时留意。

## 常见弹窗与坑
- 开屏广告；优惠券/红包到账弹窗；会员活动；安全提醒（行程分享、紧急联系人引导）；定位与通知权限。
- 未登录或登录失效：一进估价就要求登录 → 执行器发 Take_over，小满停下请 Tony 处理。
- 选完目的地会自动跳到车型选择页，没有中间确认；车型页的「确认呼叫」又大又显眼，是整个 App 最危险的按钮。
- 车型页可能默认勾了好几个车型，按钮文字会变成「同时呼叫 N 种车型」之类；改勾选不会叫车，但没必要改。
- 价格是「预估价」，随时间、路况、供需波动，隔几分钟就可能变；汇报要带查询时间。拼车分拼成/未拼成；有的是一口价；优惠券可能已自动抵扣，要分清原价和券后价。
- 上车点会被吸附到附近的推荐上车点，和任务写的地名不完全一样，让执行器把实际上车点写出来。
- 目的地同名多处（北京南站东进站口/西进站口/出发层）：任务里写清楚。
- 估价页停留太久或反复进出，可能弹「是否还需要用车」或触发验证。
- 首页的借钱、保险、信用卡广告位，别点进去。

## 敏感动作清单（执行器必须停下、小满必须先问 Tony 的）
**到「确认呼叫」前一步必须停：执行器最多走到车型选择页（估价页）读完价格就 finish，页面上的任何按钮都不再点。** 下面每一项都必须先问 Tony，并且默认由 Tony 本人在手机上完成：
- 确认呼叫 / 立即呼叫 / 同时呼叫 / 一键叫车 / 再来一单（任何带「呼叫」「叫车」字样的按钮）
- 预约用车（选完时间后的确认）、帮人叫车
- 取消订单/取消行程（可能产生取消费）
- 联系司机：打电话、发消息、快捷回复
- 支付车费、切换支付方式、开通免密支付
- 评价司机、投诉、费用申诉、申请退款
- 开发票（会填抬头邮箱并提交）
- 修改常用地址（家/公司）、紧急联系人、安全设置
- 「一键报警」「110」等安全求助按钮——绝对不能碰
- 顺风车发单、代驾下单、租车下单
- Tony 明确要叫车：执行器本身也会拒绝这一步。做法是先查估价发给他确认，然后告诉他「估价页已打开，请在手机上自己点确认呼叫」；如果他不在手机旁，建议他用随身的手机叫（司机会联系账号手机号，车会去上车点）。

## 任务描述模板
任务里一律写全称「滴滴出行」（只写「滴滴」时加载不到滴滴出行的专属经验，Launch 也可能用错名字）。改上车点 + 输目的地 + 看全车型，步数给 25–30。
- 打开滴滴出行，把上车点改成「知春路地铁站」，目的地输入「北京南站（火车站）」，进入车型选择页后用 finish 汇报每个车型的名称、预估价、预计接驾时间（有就写）和实际上车点名称。到车型选择页就停，绝对不要点「确认呼叫」或任何带「呼叫」的按钮。
- 打开滴滴出行，上车点「国贸地铁站」、目的地「首都国际机场T3航站楼」，到车型选择页后用 finish 汇报快车和专车的预估价、页面上的加价/高峰提示和已抵扣的优惠金额。不要呼叫、不要预约、不要改勾选的车型。
- 打开滴滴出行，进入我的订单/行程列表，用 finish 汇报最近 5 笔行程的日期、起点、终点、车型和实付金额。只看：不要开发票、不要评价、不要联系司机、不要申请退款。
- 打开滴滴出行，看首页有没有进行中的行程；有就用 finish 汇报车牌、车型和司机预计到达时间，没有就汇报「无进行中行程」。不要取消行程、不要联系司机。

## 待实测校准
- 首页布局：业务入口在地图上方横条还是卡片里；目的地输入框的准确文案（「你要去哪儿」/「您要去哪儿」）
- 「我的」入口：底部 Tab 还是左上角头像侧边栏；订单入口叫「订单」还是「行程」
- 选完目的地是否一定直接跳到车型选择页；中间有没有「确认上车点」步骤
- 车型选择页底部按钮的文案（确认呼叫 / 立即呼叫 / 同时呼叫 N 种车型）以及默认是否多选
- 车型列表要不要上滑才能看全；预计接驾时间在呼叫前是否显示
- 首页「家/公司/常用地址」快捷卡片点了之后是到估价页还是直接呼叫（重点核实；若会直接呼叫，要在执行器经验里禁止点这些卡片）
- 估价页停留多久会弹提示或自动刷新价格
- 登录态能保持多久，多久需要 Tony 重新验证
