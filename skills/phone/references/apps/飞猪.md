# 飞猪

## 能在这里查到/办到什么
- 机票：单程/往返/多程查询；某天的航班列表（起降时间、机场航站楼、航司、价格）；列表顶部的前后几天价格条、低价日历；舱位切换；点进单个航班看多种价格产品（退改规则、行李额、是否捆绑套餐）
- 酒店：按城市/商圈/关键词搜，列表价、评分、点评数、距离；详情页各房型价格、是否含早、取消政策
- 火车票：车次、时刻、历时、各席别余票和价格（余票数据源是 12306，飞猪在上面叠加抢票、加速包推销）
- 门票玩乐、度假线路、签证、租车、汽车票
-用户自己的：「我的」里的全部订单（待付款 / 待出行 / 退款售后）；「行程」里即将出行的航班、酒店、火车（航站楼、入住日期等）
- 会员与权益：飞猪会员等级、里程、88VIP 等专享价、红包和优惠券

## 分流：网页能不能替代
- 优先网页/搜索：
  - 某航线有哪些航班、起降时刻 → 航司官网、航班信息类网页或搜索
  - 火车车次与余票 → 12306 网页余票查询（不用登录，偶尔有验证）
  - 酒店基本信息和大概价位、景点开放时间与门票价 → 携程网页、景区官方渠道
- 必须上手机：
  - 飞猪自己的价格（会员价、88VIP 价、红包抵扣后价）——飞猪网页版功能很少，很多价格只有登录 App 才显示
  -用户的订单、行程、退款进度——账号数据
  - 「飞猪和携程哪家便宜」——两个 App 各查一次，同航班同日期同舱位对比
- 飞猪网页版阉割严重，基本不作为替代方案。

## 入口与路径
- 启动：执行器的 App 包名表里目前没有「飞猪」，Launch 会失败，执行器要回桌面找图标点开，比别的 App 多花几步；步数给 30–40。
- 首页：顶部搜索框（搜目的地、酒店、景点）；下面一大块业务入口，机票、酒店、火车票通常在最显眼的位置，门票、度假、签证、租车等在第二排或「更多」；再往下是营销内容流。底部 Tab 一般有首页、行程、消息、我的等。
- 机票：首页「机票」→ 单程/往返切换 → 出发城市、到达城市（可互换）→ 出发日期（日历，往返再选返回日期）→ 舱位 →「搜索」→ 航班列表。列表顶部是日期价格条（左右滑看前后几天）；排序（价格 / 时间）和筛选（直飞、航司、起飞时段、机场）在列表上方或底部。点某个航班进入价格产品列表。
- 酒店：首页「酒店」→ 国内 / 海外 / 民宿 / 钟点房 → 城市或位置、入住离店日期、房间人数、关键词 →「搜索」→ 列表。列表上方有排序（推荐 / 价格 / 好评 / 距离）、位置、价格星级、筛选。点进酒店，房型在下方，要上滑。
- 火车票：首页「火车票」→ 出发站、到达站、日期、只看高铁动车 → 查询 → 车次列表（余票按席别显示）。
- 订单：「我的」→ 全部订单（或待出行 / 待付款 / 退款售后）；即将出行的也能在「行程」Tab 看。

## 常见弹窗与坑
- 开屏广告；首页大促、红包、会员弹窗，有时连弹两三个。
- 登录：飞猪用淘宝/支付宝账号授权登录，登录失效时会跳授权页 → 执行器 Take_over，小满停下请用户处理。
- 机场：北京有首都（PEK）和大兴（PKX），上海有虹桥和浦东，航班列表里要看清机场；用户只要某个机场时任务里写明。
- 日期是日历，跨月要上滑；往返要先点去程日再点返程日；日期价格条一碰就换日期，读结果前要核对当前日期。
- 列表价不等于实付：常见「起」价、会员价、88VIP 价、红包抵扣后价；最低价产品可能捆绑套餐（贵宾厅、酒店券、保险）或不可退改。让执行器写出价格产品名称和退改说明。
- 国内机票列表价是否含机建燃油、国际机票是否默认含税，不同页面显示不一（待实测）；任务里要求执行器照抄页面上的税费说明。
- 酒店列表价可能是起价或不含税费，详情页房型价才准。
- 默认排序可能是「推荐」，最便宜的不一定在第一屏，要切价格排序或往下滑。
- 火车票页面会大力推抢票、加速包、组合车票。

## 敏感动作清单（执行器必须停下、小满必须先问用户的）
- 预订、提交订单、去支付、确认支付、开通免密支付
- 抢票、预约抢票、购买加速包（会预付或扣款）
- 退票、改签、退房、取消订单、申请退款、修改订单
- 在线值机、选座（改变已有订单状态）
- 新增 / 修改 / 删除常用旅客、证件、联系人
- 联系客服、在线咨询商家或酒店（等于发消息）
- 开通或续费会员、88VIP、购买权益卡；领取有使用条件的红包
- 设置降价提醒、价格订阅（改设置，轻度，也先问）

## 任务描述模板
任务里写「飞猪」，执行器才会加载飞猪专属经验。日期写全（几月几日），城市写清楚，有指定机场写机场。
- 打开飞猪，查 10月20日 北京到上海的单程经济舱机票，按价格从低到高排序，用 finish 汇报最便宜的 3 个航班：航班号、起降时间、起降机场、价格，以及页面上写的税费说明。不要点预订。
- 打开飞猪，查 10月20日 北京到成都的单程机票，点进上午 9 点左右起飞的那个航班，用 finish 汇报各价格产品的名称、价格和退改规则摘要。不要点预订、不要领券。
- 打开飞猪，搜 10月20日入住、21日离店、上海外滩附近的酒店，按价格从低到高，用 finish 汇报前 3 家的名称、评分和列表价。只看不订。
- 打开飞猪，查 10月20日 北京南到上海虹桥的高铁，用 finish 汇报 8 点到 12 点之间出发的车次、出发到达时间、二等座余票与价格。不要点抢票或预订。
- 打开飞猪，进入「我的」→ 全部订单，用 finish 汇报待出行订单的类型、日期、行程（航班号 / 酒店名 / 车次）和订单状态。只看，不要退改、不要联系客服。

## 待实测校准
- 执行器包名表缺「飞猪」（Android 包名应为 com.taobao.trip，需真机核对）；从桌面找图标启动是否稳定、要几步
- 底部 Tab 的名称（行程 / 消息 / 我的）以及「行程」里显示哪些内容
- 首页业务入口的布局和文案，机票/酒店/火车票的位置
- 国内机票列表价是否含机建燃油；国际机票含税切换的位置
- 航班列表默认排序；排序和筛选在顶部还是底部
- 酒店列表价是否含税费；会员价 / 88VIP 价的标识方式
- 淘宝授权登录的有效期，是否经常需要用户接管
- 「查列表 + 点进航班看产品」实际要多少步
