# 高德地图

## 能在这里查到/办到什么
- 两点间路线：驾车（通常 2–3 条备选，含耗时、里程、红绿灯数、是否收费）、公交地铁（换乘方案、总耗时、换乘次数、步行距离、票价）、骑行/电动车、步行
- 打车估价：路线页的「打车」方式会列出多个平台的大致价格（只看，不叫车）
- 实时路况：驾车路线按拥堵程度分段着色，耗时按当前路况估算；首页地图可打开路况图层看某片区域堵不堵
- 实时公交/地铁：搜线路名（「944路」「10号线」）看途经站、首末班车、下一班到站时间
- 周边搜索：以当前定位或指定地点为中心搜「停车场」「咖啡」「加油站」等，看距离、评分、人均、营业时间、电话
- 地点详情：地址、营业时间、电话、评分评论、图片、出入口位置（地铁站出口、商场门、火车站进站口）
- Tony 自己的数据：收藏夹里的地点、设置好的「家」「公司」、搜索历史（需登录态）
- 本地榜单：高德「扫街榜」等店铺榜单（2025 年上线，入口随版本变化）

## 分流：网页能不能替代
- 优先网页/搜索：
  - 地点的地址、电话、营业时间 → 搜索引擎、大众点评网页一般都有
  - 地铁首末班车、票价规则 → 北京地铁官网或搜索
  - 两地大致距离、「开车大概多久」这种不要求实时的问题 → 搜索即可
- 网页理论可替代、实操不划算：两点间具体路线方案。高德网页版能规划，但它是动态渲染的地图页，文本抓取基本拿不到方案明细；要「具体耗时 + 换乘 + 步行距离」时直接上手机。
- 必须上手机：
  - 按「此刻」路况算的驾车耗时、哪段在堵（实时数据）
  - 实时公交/地铁到站时间
  - 「我附近」类查询（依赖手机定位）
  - Tony 的收藏夹、家/公司（登录态）
  - 精确到地铁口、进站口、步行米数的换乘细节
- 定位提醒：这台手机用数据线连在 Mac 上，它的定位就是 Mac 所在地，不一定是 Tony 此刻的位置。Tony 说「我附近」「从这儿出发」而他可能不在家/不在电脑旁时，先问他在哪，任务里写具体地名，不要让执行器用「我的位置」。

## 入口与路径
- 首页：全屏地图。顶部是搜索框（地点、公交线路、地铁站都从这里搜）；搜索框下方常有一排分类快捷入口（美食、酒店、加油站等）；底部是可上拉的卡片，常放「家」「公司」快捷方式、「路线」入口和推荐内容；最底部是 Tab 栏（首页、附近、打车、我的等，以实测为准）。
- 查路线（最常用）：首页 →「路线」→ 起点（默认「我的位置」，需要时改成具体地名）→ 终点 → 选出行方式 Tab（驾车 / 公交地铁 / 打车 / 骑行 / 步行……，Tab 显示不全时可横滑）。
  - 另一条路：首页搜索框搜终点 → 进地点详情卡 → 点卡片上的「路线」，起点同样默认「我的位置」。
- 公交方案页：顶部可把「现在出发」改成指定时间；有偏好排序（推荐 / 时间短 / 少换乘 / 少步行 / 不坐地铁等）；点某个方案进详情才能看每段步行距离、上下车站和实时到站。
- 驾车方案页：地图上画出几条备选路线，下方卡片显示每条的耗时、里程、红绿灯、收费；底部大按钮是「开始导航」（不要点）。路线偏好（躲避拥堵 / 不走高速 / 避免收费等）在页面上的偏好入口里，改了会被记住。
- 周边：首页搜索框直接搜「三里屯附近的停车场」，或先搜地点再在详情页找「周边」；结果页顶部有排序/筛选（距离、评分、范围等）。
- 实时公交：首页搜索框输入线路名 → 线路详情 → 选方向 → 点站点看到站时间。
- 收藏夹/家公司：「我的」→ 收藏（收藏夹），里面按地点、路线等分类。

## 常见弹窗与坑
- 开屏广告：几秒后自动消失，或右上角「跳过」。
- 首次启动/升级后：隐私协议、定位权限、通知权限、新功能引导浮层（语音助手、榜单之类），不关掉就点不到地图。
- 同名地点很多：「北京南站」会出来火车站、地铁站、公交站、停车场、某个进站口。任务里要写清类型（「北京南站（火车站）」「知春路地铁站」），否则可能选到公交站，结果差很多。
- 起点默认「我的位置」：任务给了起点就必须写明「把起点改成 X」；没写时执行器会用手机定位（= Mac 所在地）。
- 出行方式 Tab 可能记着上次的选择，进路线页时停在驾车或公交都有可能，任务里要写明方式。
- 公交方案第一条常标「推荐」，不一定最快；方案列表要上滑才能看全，细节要点进去。
- 驾车耗时随路况实时变化，汇报要带查询时间；「指定未来出发时间预测耗时」的入口不稳定。
- 误点「开始导航」会进入全屏语音导航，占住屏幕，要退出导航才能继续。
- 地点详情卡上「路线」「导航」「打车」「电话」几个按钮挨在一起，容易误触。
- 首次打开地图、规划路线通常要等 1–3 秒，网络差时方案列表一直转圈。

## 敏感动作清单（执行器必须停下、小满必须先问 Tony 的）
- 叫车：路线页「打车」方式或地点页「打车」按钮之后的「呼叫」「确认呼叫」——高德打车会真的派车。只能看估价，绝不呼叫。
- 开始导航（会占住手机并播报语音，打断后续任务）
- 拨打电话（地点详情页的「电话」会直接拨号）
- 设置/修改「家」「公司」，添加或删除收藏，修改路线偏好（都会被记住，影响以后默认结果）
- 分享路线/位置、发送到车机或微信（等同发消息）
- 发表评论、上报路况、地点纠错
- 高德内嵌的酒店、门票、火车票预订入口里的下单和支付

## 任务描述模板
任务里一律写全称「高德地图」，执行器才会加载高德专属经验。改起点 + 切方式 + 点进方案详情，步数给 30 左右。
- 打开高德地图，查从「知春路地铁站」到「北京南站（火车站）」的公交地铁路线，用 finish 汇报耗时最短的一条：总耗时、换乘次数、乘坐的线路、首末两段步行距离。不要开始导航。
- 打开高德地图，查从「望京SOHO」开车到「首都国际机场T3航站楼」的驾车路线，用 finish 汇报每条备选路线的耗时、里程、是否收费，以及有没有明显拥堵（红色）路段。不要点开始导航，不要改路线偏好。
- 打开高德地图，搜索「三里屯太古里附近的停车场」，按距离排序，用 finish 汇报最近 3 个停车场的名称、距离和页面上写的收费信息。不要导航、不要打电话。
- 打开高德地图，搜索公交线路「944路」，选开往「XX」方向，用 finish 汇报「XX站」下一班车还有几分钟到站、首末班时间。只看，不要导航。
- 打开高德地图，进入「我的」里的收藏夹，用 finish 汇报收藏的地点名称（最多 20 个）。只看，不要删除或修改任何收藏。

## 待实测校准
- 底部 Tab 的实际名称和顺序（首页 / 附近 / 打车 / 消息 / 我的 中有哪几个）
- 首页「路线」按钮的位置：搜索框右侧、底部卡片里，还是两处都有
- 出行方式 Tab 的名称和顺序（「公交地铁」还是「公共交通」；骑行与电动车是否分开）；是否记忆上次的方式
- 公交方案页偏好选项的名称和位置；「现在出发」改时间的入口
- 驾车路线偏好入口的位置；是否有「未来出发时间」预测耗时
- 收藏夹在「我的」里的入口名称（收藏 / 收藏夹 / 我的地点）
- 扫街榜入口在首页卡片还是「附近」Tab
- 开屏广告时长；首次启动有哪些引导浮层
- 「改起点 + 改终点 + 切方式 + 点进方案详情」实际要多少步，25 步够不够
