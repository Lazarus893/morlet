# 淘票票

## 能在这里查到/办到什么
- 电影：正在热映 / 即将上映列表、淘票票评分、想看人数、上映日期、片长、简介、演职员、影评
- 影院：按区域、距离、品牌、特色厅（IMAX、杜比、激光、4DX、巨幕）筛影院，看距离和最低价
- 场次：某影院某天某部片的全部场次——开场时间、散场时间、语言版本（国语 / 原版、2D / 3D）、影厅名、价格（含特惠价、影城卡价）
- 余座：进入选座图能看座位剩余和分布（只看，不选）
- 演出：演唱会、话剧、脱口秀等（与大麦同源）的场次、票档、售卖状态（预售 / 售罄 / 缺货登记）
- Tony 自己的：我的电影票 / 订单（影院、场次、影厅座位、取票码）、优惠券、影城卡

## 分流：网页能不能替代
- 优先网页：
  - 影片评分、简介、上映日期、口碑 → 豆瓣、猫眼网页或搜索
  - 演出基本信息（时间、场馆、票档）→ 大麦网页或搜索
- 网页不好使：猫眼网页有影院和场次，但价格数字常用特殊字体显示，文本抓取拿不准；场次时间可参考，价格别信。
- 必须上手机：
  - 淘票票上此刻的价格（特惠价、影城卡价、券后价）和余座
  - 「今晚 7 点后、望京附近、IMAX 厅」这类按地点 + 时间 + 厅型组合筛的查询
  - Tony 的电影票、取票码、订单状态、优惠券——账号数据
- 「附近」「距离」以手机定位为准（手机在 Mac 旁边）；Tony 想去的地方不在 Mac 附近时，任务里写明商圈或影院名。

## 入口与路径
- 启动：执行器的 App 包名表里目前没有「淘票票」，Launch 会失败，执行器要回桌面找图标点开，多花几步；步数给 30–40。
- 首页：左上角是城市（应为北京），旁边是搜索框（搜影片、影院、演出）；下方是正在热映 / 即将上映的海报和营销位。底部 Tab 一般有首页、影院、演出、我的等。
- 按影片找场次：首页点影片海报 → 影片详情 → 底部「购票」类按钮（这一步只进影院列表，不扣钱）→ 影院列表（顶部日期 Tab：今天 / 明天 / 后天…；筛选：区域、品牌、特色厅、排序）→ 点影院 → 场次列表。
- 按影院找场次：底部「影院」Tab 或首页搜影院名 → 影院详情 → 顶部影片海报横滑选片 → 日期 Tab → 场次列表（上滑看全）。
- 看余座：场次右侧的「购票」→ 选座图。只看不点座位。
- 我的票：「我的」→ 电影票 / 订单 → 点进看取票码和影厅座位。
- 演出：「演出」Tab 或首页搜演出名 → 演出详情 → 场次与票档。

## 常见弹窗与坑
- 开屏广告；新人红包、优惠券弹窗；定位城市切换提示；通知权限；版本更新。
- 登录：淘宝 / 支付宝授权登录，失效时 Take_over，小满停下请 Tony 处理。
- 影片详情页可能自动播放预告片（有声音），不影响读信息。
- 同品牌多家店：「万达影城」「CGV」在北京都有很多家，任务里写全分店名或商圈。
- 日期 Tab 只显示有排片的日期；临近开场停售的场次会置灰。
- 价格标签多：「特惠」通常限量、限新用户或每人限购几张；「影城卡价」要持卡；影院列表的「起」价是该影院最低一档。汇报要写清是哪种价。
- 场次列表长，晚场要上滑；同一时段可能 2D 厅和 IMAX 厅都有，注意厅名。
- 选座图里点座位只是选中，但底部会出现「确认选座」类按钮，一点就锁座并生成待支付订单，这是红线；所以干脆不点座位。
- 演出页的「预约抢票」「缺货登记」都是提交动作，不是查看。

## 敏感动作清单（执行器必须停下、小满必须先问 Tony 的）
- 选座后的确认选座 / 锁座、提交订单、支付（锁座会占座十几分钟并生成待支付订单）
- 退票、改签、取消订单
- 购买或续费影城卡、开通会员、加购小食套餐
- 演出：预约抢票、缺货登记、立即购买、选票档后的确认
- 领取有使用条件的优惠券
- 发表影评、打分、点「想看」（会公开挂在 Tony 账号下）
- 联系客服
- 取票码 / 二维码属于凭证：只发给 Tony 本人，不转给别人

## 任务描述模板
任务里写「淘票票」，执行器才会加载淘票票专属经验。片名用书名号，影院写全分店名。
- 打开淘票票，确认城市是北京，搜索电影《XXX》，进入购票后的影院列表，日期选今天，用 finish 汇报离「望京」最近的 3 家影院的名称、距离和最低价。不要进入选座。
- 打开淘票票，搜索影院「XX影城（XX店）」，在影院页选电影《XXX》和明天，用 finish 汇报晚上 7 点以后的全部场次：开场时间、语言版本、影厅、价格。不要点购票。
- 打开淘票票，查《XXX》在「XX影城（XX店）」今天 19:30 那场的选座图，用 finish 汇报大致还剩多少座、中间几排是否还有相邻的 2 个空位。只看，绝对不要点座位或「确认选座」。
- 打开淘票票，进入「我的」里的电影票，用 finish 汇报最近一张未使用电影票的影片、影院、场次时间、影厅座位和取票码。只看，不要退票改签。
- 打开淘票票，在演出里搜「XXX 北京站」，用 finish 汇报场次日期、场馆、各票档价格和售卖状态。不要预约抢票、不要缺货登记。

## 待实测校准
- 执行器包名表缺「淘票票」（Android 包名需真机核对）；从桌面找图标启动是否稳定、要几步
- 底部 Tab 的名称（是否有「影院」「演出」「社区」）
- 影片详情底部按钮的准确文案（购票 / 特惠购票 / 选座购票）
- 影院列表筛选项的名称和位置（区域、品牌、特色厅、排序）
- 场次价格是否含服务费；特惠价的标识和限购写法
- 选座图能否直接看出剩余座位数，还是只能数；进选座图是否需要登录
- 选座页确认按钮的准确文案
- 「我的」里电影票入口的名称；取票码是直接显示还是要再点
- 预告片自动播放会不会挡住点击
