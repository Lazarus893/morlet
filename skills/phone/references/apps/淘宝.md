# 淘宝

## 能在这里查到/办到什么
- 订单：我的淘宝 → 待付款 / 待发货 / 待收货 / 退款售后 / 全部订单，每单的商品名、实付金额、下单时间、状态
- 物流：待收货订单卡片上的最新一条物流；进订单点「查看物流」看完整轨迹、快递公司、运单号、派送员或驿站
- 退款售后进度：每条售后的状态（待商家处理、待寄回、退款成功）和退款金额
- 购物车：商品、规格、现价，以及「比加入时降价」一类的降价提示、失效宝贝
- 收藏夹、足迹、关注店铺：收藏宝贝的现价、是否降价、是否已失效
- 商品搜索比价：价格（标价 / 券后价 / 到手价）、已售数量、店铺名、天猫或旗舰店标识、发货地
- 商品详情：各规格价格、可领优惠券、店铺评分、评价与带图评价、问大家、发货时效
- 淘宝闪购（外卖与即时零售）：附近门店商品和送达时间，需要定位
- 红包卡券：账户里可用的红包、优惠券、88VIP 权益

## 分流：网页能不能替代
- 优先网页，不上手机：
  - 商品参数、评测、口碑 → 网页搜索（什么值得买、品牌官网等）信息更全
  - 历史价格走势 → 比价网站有价格曲线，淘宝 App 里本来就没有
  - 已经知道运单号的快递 → 快递100 或快递公司官网直接查
- 必须上手机：
  - 订单、物流、退款、购物车、收藏、红包：全部依赖 Tony 的登录态，Mac 上没有登录，网页版会要求扫码登录
  - 「淘宝上现在卖多少钱」：网页版未登录搜索会被拦到登录页，也没有 App 专享券、百亿补贴价、淘金币抵扣，价格以 App 为准
  - 淘宝闪购：需要定位和 App
- 一句话判断：问「我的」（我的订单、我的包裹、我的购物车）→ 手机；问「这东西怎么样」→ 先网页；问「淘宝卖多少」→ 手机

## 入口与路径
- 底部 Tab 从左到右大致是：首页、视频、消息、购物车、我的淘宝（名称以真机为准）
- 首页顶部是搜索框，框内右侧有拍照搜同款的相机图标，最右是「搜索」按钮；搜索框附近有一排频道 Tab（推荐、闪购、国补等，随活动变化）
- 订单：我的淘宝 → 订单区的待付款 / 待发货 / 待收货 / 退款售后，旁边「全部订单」
- 物流：我的淘宝 → 待收货 → 点订单 → 查看物流
- 找历史订单：全部订单页顶部有搜索，可按商品名搜
- 购物车：底部购物车 Tab，顶部有降价等筛选标签
- 收藏、足迹：我的淘宝头像下方一排入口
- 搜索结果排序：顶部 综合 / 销量 / 价格（再点切换升降序）/ 筛选（最右，可设价格区间、发货地、天猫、包邮）

## 常见弹窗与坑
- 开屏广告带「跳过」倒计时；进首页后常有红包、88VIP、大促全屏弹窗，关闭按钮多在弹窗下方的圆形 X
- 大促期（618、双11）首页、购物车、商品页层层弹窗，步数要多给（加到 35–40）
- 定位、通知权限弹窗：只有闪购类任务需要定位，其余拒绝
- 首页右下角有悬浮红包球或活动入口，底部 Tab 上方偶有横幅，容易误触
- 搜索结果夹杂广告位，同款商品多、价差大 → 让执行器同时汇报店铺名和已售数量，便于分辨
- 价格有多种：标价、券后价、到手价、百亿补贴价、88VIP 价、淘金币抵扣价 → 任务里要求执行器注明报的是哪一种
- 商品详情页默认展示最低价规格的价格，不代表 Tony 要的那个规格
- 已完成的订单只在「全部订单」里，不在待收货；订单多时要往下翻
- 天猫超市、淘宝闪购、飞猪等子业务的订单卡片样式不同
- 物流详情里最新状态在最上面

## 敏感动作清单（执行器必须停下、小满必须先问 Tony 的）
- 立即购买、提交订单、付款（含免密支付、先用后付）
- 加入购物车、从购物车删除、修改购物车里的规格或数量
- 确认收货（确认后钱直接打给卖家，无法撤回）
- 申请退款或退货、撤销退款、填写退货单号、取消订单、删除订单、延长收货
- 联系卖家或客服（旺旺发消息）、发评价、追评
- 修改收货地址（订单内或账户设置里）
- 领券、领红包、签到、开通或续费 88VIP、使用淘金币
- 收藏或取消收藏、关注或取关店铺
- 任何「授权」「开通」「绑定」按钮

## 任务描述模板
（任务开头写「打开淘宝」，执行器靠任务里的 App 名加载淘宝专属经验）
- 打开淘宝，进入我的淘宝→待收货，逐个查看订单，用 finish 汇报每单的商品名、快递公司和最新物流状态。不要确认收货，不要联系卖家。
- 打开淘宝，搜索「XX」，按销量排序，用 finish 汇报前 5 个商品的标题、店铺名、页面价格（注明是标价还是券后价）和已售数量。不要加入购物车，不要购买。
- 打开淘宝，进入我的淘宝→退款售后，用 finish 汇报每条售后的商品名、退款金额和当前进度。不要撤销或修改任何退款申请。
- 打开淘宝，进入购物车，用 finish 汇报所有带降价提示的商品名、现价和降了多少。不要删除或结算任何商品。
- 打开淘宝，进入我的淘宝→全部订单，搜索「XX」，用 finish 汇报找到的订单的下单时间、实付金额和状态。只看不改。
