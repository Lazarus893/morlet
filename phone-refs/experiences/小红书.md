# 小红书 App 经验库

## 启动与首页
- Launch 后进入首页「发现」页；顶部 Tab：关注、发现（默认）、城市名（基于定位）
- 左上角有消息图标，右上角放大镜是搜索入口
- 底部 Tab：首页、市集、+（创作）、消息、我；「+」是发布，不要点
- 弹窗：「开启通知」点「以后再说」或 X；「青少年模式」点「我知道了」；「发现新版本」点「以后再说」；活动弹窗点右上 X；底部广告横幅忽略或点 X

## 搜索
- 点右上角放大镜进搜索页：顶部搜索框（含热搜 placeholder）+ 历史记录 +「猜你想搜」
- 输入后点「搜索」按钮可能不生效，优先直接点下拉建议里最匹配的一项（建议列表实时更新）
- 点过搜索框右侧 ⓧ 清空后，要再点一次搜索框文字区域获取焦点才能重新输入
- 结果页顶部筛选 Tab：全部、用户、商品、经验、问一问等；二级有综合、最新等；要按点赞排序或只看图文，找结果页右上的「筛选」
- 结果是双列瀑布流（封面+标题+作者+点赞数），左列帖子大约在横向 1/4 处，右列大约在 3/4 处；帖子高度不一，点错直接 Back 重试
- 跳过标「赞助」「广告」的帖子和直播卡片；总结/调研类任务从「全部」浏览，图文和视频混排

## 帖子详情页
- 上半部分是图片/视频，多图左右滑切换；攻略常写在图片里，逐张看并用 Note 记录
- 下半部分：标题、正文（长文点「展开」，可能要多次滑动才看完）、标签、发布时间
- 底部：点赞、收藏、评论数、分享按钮——只读数字，不要点
- 评论区在正文下方，上滑查看；热门评论在前，点「查看更多评论」展开
- 「展开 N 条回复」要点开才能看完整讨论；高赞评论最有代表性，优先记录

## 滑动与加载
- 详情页上滑看评论：start=[500,700], end=[500,200]，距离不小于 400
- 搜索结果页上滑加载更多（瀑布流无限滚动）；图片加载慢就 Wait

## 千万别做（确需点时 Tap 必须带 message 标注重要操作）
- 双击笔记图片（会直接点赞）；点爱心、星标收藏、评论输入框、作者旁的「关注」、分享
- 私信、市集「购买」「加入购物车」；登录提示（评论/收藏时触发）出现就 Back 返回
