# 通义千问 App 经验库

## 启动与首页
- 包名：`com.aliyun.tongyi`
- Launch 后进入对话首页
- 顶部 Tab：**千问办事**（智能体/工具）、**千问**（对话，默认选中）
- 左上角 ≡ 菜单（历史对话列表）
- 中间展示欢迎语："我是千问" + "为你答疑 办事 创作，随时找我聊天"
- 下方有推荐问题卡片（如"热点：..."、生活问题等）

## 对话功能
- 首页即对话页，无需额外导航
- 底部输入框："发消息或按住说话..."
- 输入框左侧有语音按钮，右侧有相机和 **⊕** 按钮
- 底部功能快捷栏：深度思考、AI生图、拍题答疑
- 发送消息：输入文字后点击发送按钮
- **新建对话**：左上 ≡ 菜单打开侧边栏 → "新建对话"；或者返回首页重新点击对话 Tab

## 记录回答
- 回答生成有打字机动画效果，Wait 等待完毕再截图
- 千问回答通常结构化较好（分点列举），信息密度高
- 长回答需向上滑动查看完整内容
- 使用 Note 记录关键结论段

## 千问办事 Tab
- 顶部点击"千问办事"可切换到智能体/工具模式
- 包含各类预设工具（写作、翻译、编程等）
- 做竞品测试时应使用"千问"Tab（通用对话）

## 常见弹窗
- 首次打开可能弹出隐私协议/权限请求，点"同意"/"允许"
- 版本更新提示：点"以后再说"或"稍后"
- 功能引导覆盖层：点击空白或"跳过"关闭

## 启动方式
- **推荐使用 monkey 命令启动**：`adb shell monkey -p com.aliyun.tongyi -c android.intent.category.LAUNCHER 1`
- 比 `am start -n` 更可靠，避免 Activity 类名不匹配的问题

## 坐标经验（1080x2376 分辨率）
- **发送按钮**：FrameLayout 类型，坐标约 (965, 2064)，无明显 resource-id
- 建议用 `uiautomator dump` 查找 clickable 的 FrameLayout 确定精确位置
- 输入框在屏幕底部，与豆包类似需要点击较低 y 坐标位置

## 注意事项
- 通义千问 App 名为"通义"，在桌面上可能显示为"通义千问"或"通义"
- 确保在"千问"Tab 下进行对话测试，不要进入"千问办事"Tab
- 底部"内容由AI生成"提示文字不可点击，不要误触
- 回答生成期间不要操作页面，等生成完毕后再截图或滑动
