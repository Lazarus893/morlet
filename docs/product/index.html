用自己的资料与工具

Morlet 通过小满总管与事务 Bot 承接任务。账号、资料范围和设备权限，由自己的实例管理。

能力当前范围
执行 AgentDSH、Codex、WorkBuddy。可按事项选择、继续处理与带上下文交接，具体能力取决于适配器与授权。
Google 资料邮件、日历、Drive、Docs、Sheets、Contacts 的受控读取，需本人授权相应范围。
GitHub 与 XGitHub 仓库、待审 PR、通知、发布与提交；X 时间线取决于账号授权和 API 额度。
本地文件已授权目录内的检索与普通文本读取，系统权限由本人管理。
私有 Nango统一承接支持服务的授权与只读请求；新增 App 仍需业务能力适配。
DSH Remote查看和管理已授权设备的原生会话、继续对话、停止与单次审批。与手账任务执行链路各有边界。
通信渠道Web、微信、iMessage，以及按实例配置的桌宠。绑定后可从不同入口交代与续聊；任务共用记录，回复默认回到来信渠道。
手机操作可配置 Android 或 iPhone 执行链路，需设备、系统权限和具体任务授权。

服务显示已连接，不代表所有内容已经读完，也不代表获得了任意写入权限。撤回授权后，相关持续任务停止后续读取。

从一件真实的小事开始

当前是单主人工作区。独立试用需各自安装，连接自己的 Agent 和账号。

  1. 在自己的电脑或受控服务器部署独立实例。
  2. 按任务需要授权资料与通信渠道。
  3. 交代一件事，检查结果，再回到同篇继续聊。
明天上午十点有产品评审。读取我指定的两份材料，整理关键进展、风险和三个需要拍板的问题，保存成一页会前准备。
当前版本的使用条件

后台巡查

DSH 提供可核验的公开网页读取；Codex 支持受控资料源巡查，WorkBuddy 暂未支持此类后台任务。

外部提醒

巡查提醒目前支持已选择的 iMessage／桌宠渠道，真实投递需对应实例验证；微信尚不属于巡查提醒渠道。

常驻与文件

持续执行依赖设备开机、用户服务运行和执行端在线。文件标注“保存在执行电脑”时，不代表已上传到浏览器。

第三方服务

米家、网盘、打车、咖啡等服务没有在本版全部接通，需要逐项核实接法、本人授权和真实查询验证。
