# 小满首次使用

先用一件真实的事认识小满。Web、微信和 iMessage 是交代入口；Agent 负责处理；材料、选择、进展与回报保存在手账。

## 从已有材料开始

从「手账 → 认识小满」进入。已有近期材料时，引导直接呈现可选择的真实内容，复用手账的选择 Widget。每条选择标明来源和日期；点击只保存选择，点击「让小满跟进」才开始执行。打开页面最多创建本地引导记录，不会自动选择、启动任务或发送消息。

跟进事项、执行状态和结果绑定在同一份账本。离开、刷新后可继续；超时或提交结果不确定时，保留选择和原始回执，按状态核对或重试。回报区分部分结果和完成，不把模型回复等同于核实成功。可打开事项继续勾选清单，也可归档引导。

材料标题与摘要使用已保存的来源数据，点击直达对应阅读项。完成后从手账书签回看同一件事：「产物」查看结果，「对话」补充要求、继续跟进。

## 自己交代一件事

没有近期材料时，直接打开交代入口。有材料时，入口收在下方的「自己交代一件事」。展开或从其他页面带入内容不会覆盖已有未发送草稿。自然交代围绕同一事项追问、展示计划、等待本人确认、入账和生成组件，详见[首用的一件生活事](first-task.md)。

## 按需连接与恢复

Agent、消息入口和权限放在「设置」。已有在线管家可直接开始；无可用执行端时，在当前任务提供连接入口。消息或连接状态读取失败时，错误及重试显示在页面上方，不要求先展开设置。会话失效须刷新后继续，草稿不会自动发送。

更换入口或 Agent 不改变实例职责与已有会话绑定。在线、权限授予、实际访问、执行回执分别核对。连接微信仍需本人扫码、确认身份并重新发信；iMessage 仍需收发身份、后台权限和桥在线，见[连接说明](getting-connected.md)。

当前优先桌面体验。选择、跟进和结果回报使用同一套控件，键盘及减少动效模式沿用手账设置。窄屏保留响应式布局，书签目录按需展开。

OAuth、扫码、系统授权和审批由本人确认；引导不会自动申请全部权限、外发消息、购买或订座。目录授权不等于全盘访问，手机在线不等于录屏授权。

查看记录使用 `xiaoman_journal` 返回的可信地址。宿主从实例 `PA_WEB_ORIGIN` 生成 `view.url`；无公共地址则给出导航路径。`#journal/<itemId>` 可直接查看和刷新回看，仍经过当前页面和 owner 账本校验。
