# 独立实例的访问与恢复

每个实例只有一位主人。别人试用小满时安装自己的实例；公开介绍页与私人手账分开。浏览器打开入口不会自动取得主人权限，Agent 和通信桥的配对令牌也不能登录手账。

安装后在运行小满的电脑上执行 `./scripts/pa.sh owner`，本人输入至少 12 位密码。密码使用 Better Auth 的密码哈希；会话与实例密钥只在 `.runtime/owner/`。不把密码放进命令参数、仓库、日志或聊天。

通过 HTTPS 或本机 `127.0.0.1` 登录。远程明文 HTTP 不接受登录；不能把 SSH 隧道当成给所有人的共享入口。部署者应配置受浏览器信任的证书，并将 `PA_WEB_ORIGIN` 设为实际 HTTPS origin，不能跳过证书警告。部署模板支持 `tls_certificate`、`tls_certificate_key` 两个本机路径；二者必须同时提供。

设置页可退出当前登录或退出其他设备；主动退出同时清理本浏览器的小满草稿缓存。会话最长保留 7 天，服务重启不会自动放行未登录的人。忘记密码时在实例电脑上执行 `./scripts/pa.sh owner --reset`；重设会撤销全部旧会话。没有本机管理权限的人不能通过网页重置主人密码。

## 备份与恢复

暂停实例写入后执行：

```sh
python3 scripts/instance_backup.py backup /private/location/xiaoman-state.zip
python3 scripts/instance_backup.py restore /private/location/xiaoman-state.zip --root /path/to/unused-instance
```

备份包含本实例的配置、账本、Hub、连接授权、主人认证、主动跟进、记忆、Agent 状态和个人技能。只备份指定状态目录，不打包截图、上传原件、缓存、框架依赖或外部 CLI 的登录文件。附件提取文字仍可能保存在 Hub 中；备份含私人数据与凭据，默认权限 0600，不能当成产品安装包分享。

SQLite 使用在线备份接口，并检查备份期间的变化；发生并发写入时明确失败，暂停写入后重试。恢复先核对全包摘要、路径和数据库完整性，只允许目标没有 `.runtime` 与 `.env`。恢复时仍须停止其他进程写入目标目录；遇到并发冲突会停止且不覆盖已有文件，改用新的空目录恢复。恢复到另一台机器后重新配置机器路径、连接和外部 CLI 登录，并重设主人密码撤销复制过来的会话；不要同时启动两个共享相同通信身份的实例。
