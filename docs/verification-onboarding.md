# 首次使用引导验收

更新时间：2026-10-14。本文件记录通用状态契约与离线验收，不包含实例账号、凭据、设备标识或部署地址。

## 验收目标与入口

主流程是确认一个 Agent、选择消息入口、交代第一件生活小事。Web 可直接开始；微信、iMessage、第三方账号、文件和手机按需接入。已有实例可回到引导继续补齐连接，进入页面不会重新配对、变更职责、撤回权限或提交任务。

点击生活示例应只打开草稿。用户确认后才发送；生成新 Web 对话不能沿用一段 IM 对话的回信来源。事实保存、Agent 汇报、AI 整理和消息送达分别展示。

## 可信状态契约

| 能力 | 可依据的证据 | 不能推出的结论 |
|---|---|---|
| CLI 与安装 | `state.installed` 是所选 CLI 可执行文件存在；本机安装器返回 `installed` 或 `reused` | CLI 已登录、已有在线端、任务可以完成 |

| Agent 回执 | `run.status=completed` 表示返回文本；同时有 `report.outcome=completed` 表示收到完成汇报 | 共用待办已完成、报告经过独立业务核验、所有能力可用 |
| 微信 | 启用、当前宿主已连接、精确扫码结果、配置版本已加载、允许身份、该身份实际来信 | 扫码等于允许联系；保存 allowlist 等于运行中已加载；历史账户等于当前登录 |

| 可选账号与设备 | Mac 桥状态与每个权限的 `granted`、新鲜 `verified` 独立展示 | item 的 `connected` 等于全部权限；OAuth 等于 Chief 已有对应业务工具 |

## 自动化验证

独立测试文件为 [`tests/onboarding.test.mjs`](../tests/onboarding.test.mjs)。状态测试用 Node VM 加载正式 IIFE、直接调用无 DOM 副作用的 `derive`；真实 Hub 和 HTTP 用例使用临时 SQLite、临时监听端口及替代宿主，不连接模型、微信、OAuth 服务或手机。

```sh
node --test tests/onboarding.test.mjs
```

覆盖范围：

- 缺快照与空实例、CLI 发现与进程启动、已配对离线到心跳在线、撤销连接、真实 45 秒心跳失效。
- 有文本回答但未完成汇报、部分完成汇报、报告完成但 run 尚未结束；收到完整执行回执也不能凭空产生生活账本记录；已有实例恢复及状态计算不改输入。
- 微信禁用、离线历史账号、新扫码等待或失败、保存未应用的配置、允许身份与来信分离。
- iMessage 心跳但系统权限异常；同一对话的两种通道回执正确归属；已提交和已发送不冒充送达。
- 桥在线但手机录屏未授权、授权但未验证、空权限数组、默认文件范围不能等同全盘。
- Hub/连接 API 各自失败，不把未知视作完成，不清除已保存手账；缺设计角色、失败设计及旧 revision 排版保留记录。
- 页面会话过期单独要求刷新页面，不能反复读取失效会话；设备状态超时不触发整页会话恢复，也不清除已保存手账。
- 只有 `journal:<runId>:<callId>` 的 `done` 且 `saved=true` 效果回执才出现在该 run 的 `journalItemIds`；同项去重，pending/uncertain/未保存/其它效果不链接，快照不暴露 digest、token 和 item 原文。
- 正式 HTTP 仅公开白名单引导资源；资源保持 CSP；无浏览器会话不能读取状态 API，伪造 Host 与私有文件路径仍被拒绝。

本轮状态：24 项全部通过，无失败、跳过或取消。包含真实临时 Hub 和 HTTP 验证；没有调用真实模型或外部服务。

## 当前可交付范围与真实验收

## 独立可访问性与交互复核

本轮独立复核只读取正式源码和主任务提供的桌面、375px 与 305px 截图，没有操作共享浏览器。未发现阻止使用的 HIGH/MEDIUM 问题。控件使用原生 button、fieldset/legend、label 包含的 radio、details/summary；步骤用 `aria-current`；有跳到主内容入口、显式焦点边框和至少 44px 高度的主动作、步骤、展开与权限入口。页面只突出一个主 CTA，示例操作和记录保存分开。

静态不透明 CSS 色值对比：正文弱强调色对页面背景 5.65:1、对选中浅底 5.20:1，主按钮白字对绿色 7.63:1，错误文案对错误浅底 5.67:1，焦点边框对选中底色 6.59:1。这些是源码色值计算，不冒充逐像素测量。disabled 主按钮约 3.21:1，不作为可操作控件的对比失败结论。

低风险发现如下。实际修复情况应由对应作者确认；读屏结果仍须实测。

| 严重度 / 置信度 | 位置 | 当前实现 | 建议 | 影响 |
|---|---|---|---|---|
| LOW / 高 | `style.css:5`；`onboarding.css:124` | 全局按钮按压位移 1px；减少/关闭动效规则仅取消 transition 与 animation | 同时在引导的减少/关闭动效规则中取消按压 transform | 用户选择关闭动态时仍有微小位移，不影响完成任务 |

## 浏览器完整流程与修复复核

CUA使用正式源码、受保护HTTP、真实临时Hub/lease工具和临时SQLite；模型与设计仅在该层采用明确的隔离替身。Web示例只建新对话草稿，0条执行；本人确认发送后产生1条执行，保存回执直接打开prep/agenda，刷新保留原对话与同一事项。无Agent仍可手动保存；设计失败明确保留记录；微信示例只复制没有外发；拒绝审批没有写入；登录失效显示修复步骤，带回草稿后没有新增执行。已存会话无效时要求明确重选，不自动掉进旧IM会话。

失效页面会话经正常刷新入口恢复；向导与父页面停止无意义自动重试，不重放写入。配对表单的页面离开弹层选择继续编辑后，原输入及焦点保留；配置下载仅清与所生成版本相同的草稿，多份下载互不清状态，链接仅卸载或替换时回收。后两项配置版本/并发边界由独立VM探针复核，并不冒充已安装真机助手。保存中阻止离开；旧异步回看不抢新页面；轮询与新对话回执同ID去重。

375px/305px实际布局无页面横向溢出，手机仅引导页将产品导航按需展开，完整步骤名称保留于ARIA。记录主查看动作在375px首屏约550px处，示例与额外权限按需展开；关闭/减少动效消除按钮位移和步骤移动，证据与权限明细有展开标记。未命名可见输入为0，独立静态对比、44px目标及截图审查通过。原生summary在工具AX里呈button但DOM定位应使用summary；不把定位差异当用户交互缺陷。未做VoiceOver、高对比、200%缩放认证，重复同一错误的实际朗读仍待验证。

本机逐项截图在_temp/onboarding/；不进入源码包。独立状态与HTTP套件24项通过；最终相关业务回归214项通过，随后导航保护与恢复的针对回归88项通过。修改后的独立UI使用CUA验证；未在本轮运行旧Playwright UI脚本。真实内网与模型实例验收另存私有发布证据，不能从隔离模型替身推断完成。
