# 小满 Web UI

主导航为「手账」「聊天」「设置」。手账按事务、巡查、资料组织结果；聊天包含全员群及每位 Bot 的固定私聊；设置集中呈现服务、设备、执行 Agent 与消息渠道。视觉沿用石白、墨色、森林绿和紧凑的手账排版，布局与组件约定见[生活手账](life-journal.md)。运行页面在 `plugins/webui/public/`。

## 启动与首次连接

先安装项目依赖及希望使用的 Agent CLI，再启动：

```bash
./scripts/pa.sh setup
./scripts/pa.sh web
# 自定义端口：./scripts/pa.sh web --port 3083
```

打开 `http://127.0.0.1:3083/#journal`。默认只监听本机；远程部署须按[部署说明](deployment.md)配置服务地址与访问边界。它读取 `.runtime/pa.json`；没有配置时读取模板，但不会仅因打开网页而启动 PA、调用模型或连接设备。

1. 在「设置 → 执行 Agent → 连接 Agent」连接已安装并登录的 Codex 或 WorkBuddy；DSH 宿主和本机配置在「运行设置」检查。
2. 等待执行端在线，进入聊天向 Mori 或对应 Bot 发送任务，核实登录和执行。仅检查程序已安装不能证明账号与额度可用。
3. 首次使用从 Mori 私聊交代实际任务；有已授权资料时可带入候选，实际结果形成后进入手账。
4. 按需连接微信或 iMessage：本人扫码、确认白名单或授予 Mac 系统权限，确认本人绑定后，可与 Web 共享同一 Bot 私聊。允许联系不等于确认本人；其他联系人保持隔离。步骤见[新用户接入](getting-connected.md)。

允许多个 ID 表示他们都属于同一个信任范围，工作区与记忆共享。此项目不是隔离的多租户服务。

关闭浏览器不停止 PA。由 Web 服务启动的 PA 可以在页面停止，退出 Web 服务也会停止它；由其他终端启动的 PA 只能回原终端停止。网页不管理系统自启动、休眠唤醒或外部进程。升级代码后，旧进程可能还没有管理接口，需在其原终端重启一次。

## 页面能力

- **聊天**：全员群、固定 Bot 私聊、跨端来源和按时间排列的消息。点击 Bot 名字查看执行 Agent 与安排。
- **手账**：类型目录、主题书签、搜索、同源时序归并、Widget 与结果回报；篇内消息可定位唯一原文。同源资料默认展示最新一期，历史从篇内日期或搜索进入。详见[生活手账](life-journal.md)。
- **持续跟进**：固定一篇，保存范围、频率、提醒与结束时间，可暂停或撤权。默认只写手账，失败和投递不确定保持可见。详见[日常巡查](routines.md)。
- **设置**：服务与设备、消息渠道、执行 Agent，以及折叠的提醒偏好和运行设置。连接状态、权限、真实读取与送达分开核对。

配置保存与服务加载是两件事。页面显示运行中微信通道报告的配置版本；只在它与已保存版本一致时说明新设置已加载。停用微信后无通道报告，因此不伪称运行状态已确认。核心或全局配置的应用会重新加载微信通道，可能中断当前处理；请尽量在空闲时调整。

「已登录」表示持有已验证的微信账号。最近一次收取消息失败时显示连接异常；不以账号存在来宣称发送成功。二维码由已锁定的本地 QR 编码库生成，不上传二维码内容给图片服务。

移动设备的检查仅读取 ADB/WDA 状态，不触屏、不截图、不执行任务。手机视觉模型仍通过 `.env` / `phone.json` 配置；Web 不管理 API Key。详见 `docs/iphone.md`、`docs/adapters.md`。

## 主动跟进的一致性

微信、Web 与 CLI 读取同一个台账。运行中的 PA 持有账号台账的独占 SQLite 租约：Web 通过权限为 0600 的 Unix socket 让该进程处理变更，而不是直接改它正在持有的文件。

仅在连接 socket 之前明确发现服务离线时，Web 才能获取同一租约并修改已有账号记录。租约被占用则拒绝写入；请求超时或结果不明时不尝试离线重放。Web 不伪造微信来信，不刷新会话 token、活跃时间或首日开场状态。

每次修改携带账号、用户和版本。过期版本返回冲突；表单保留输入，重新载入后再核对。打开中的草稿固定归属原账号与用户，后台列表变化不会让它转给另一个人。配置写入也有文件锁、原子替换、持久化和乐观版本校验，CLI 与 Web 并发保存不会静默覆盖彼此。

完成「正在提交」的事项时，撤销会恢复为送达未知，而不是重新进入待发。送达未知不自动重发；用户主动延后才安排下一次尝试。已经发出的消息不能撤回。过期事项不会集中补发，恢复暂停也不会跳过静默和额度。

微信提醒依据待办、最近对话、微信上下文和用户偏好，不读取系统勿扰或全天屏幕。资料巡查使用单独授权的数据源，规则与回报独立保存。电脑休眠、服务退出或渠道上下文失效都可能影响提醒；它不是精确闹钟。

## 本机访问边界

HTTP 服务校验 Host 与配置的服务地址；浏览器会话使用 HttpOnly、SameSite=Strict cookie。变更接口要求同源 Origin、CSRF token、JSON 内容类型和有界请求体。静态资源为显式白名单，禁止任意读取运行目录；任务产物经过所属记录与路径检查后提供。页面有 CSP、禁止嵌入与缓存。台账快照只返回必要字段，不返回微信凭据、上下文 token 或模型配置密钥。

这是同一 OS 用户下的本机控制台，不抵御已能读写该用户文件的其他本地进程；不应暴露到公网。任务内容和称呼通过文本转义渲染。配置及记录保存在本机，但微信消息会经过微信，Agent 也可能使用它配置的云端模型。

## 实现与验证

Node 原生 HTTP 服务复用已有运行依赖，Python 桥接既有配置/检测代码。页面外壳使用 HTML/CSS/JavaScript；富文本与 Widget 复用 OpenUI/React 组件，源文件为 `plugins/webui/surfaces.jsx`，通过 `npm run build:surfaces` 构建受版本管理的前端资源。

- `plugins/webui/server.mjs`：访问保护、HTTP API、服务进程、扫码生命周期。
- `plugins/webui/control.mjs`：实时 IPC 与离线台账编辑。
- `plugins/proactive/management.mjs`：共用管理命令和安全快照。
- `scripts/web_config.py`：配置、应用、Agent 与设备检测。
- `tests/webui.test.mjs` / `tests/test_webui.py`：管理协议、并发、租约、账号边界、HTTP 与进程契约。
- `tests/webui.browser.mjs`：可选 Playwright 浏览器验收，使用临时运行目录、假微信和假 Agent，HTTP/配置/台账代码是真实的。

```bash
./scripts/pa.sh check
python3 -m unittest discover -s tests -v
python3 scripts/smoke.py
# 已安装 Playwright 时：
node tests/webui.browser.mjs
```

浏览器验收可用 `PA_PLAYWRIGHT_MODULE` 指向现有 Playwright 包。截图写入 `_temp/webui-acceptance/`，不进入源码包。自动测试不会向真实微信发消息或操作真机。
