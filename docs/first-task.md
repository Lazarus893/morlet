# 用真实资料完成第一件事

从「聊天 → Mori」交代一件事，或点击空手账的「找 Mori」。后者只读取近期已有来源依据的材料，把其中一条带入可编辑草稿；不再先创建一篇空白引导。发送前可以调整目标、资料范围和期限，已有未发送草稿不会被覆盖。

没有近期材料时，先请你选择资料。可以从一个明确问题开始，例如：“读取我指定的产品评审材料，说明当前进展、主要风险和三个需要拍板的问题，保存成一页准备清单。”Agent 只能使用本轮提供或已授权的来源；缺少事实时明确留空，不自动扩大到日历、邮箱或其他 App。

## 完成标准

发送后，先看是否读到了指定材料及其覆盖范围；需要保存的事实、问题和选项进入同一篇手账。「产物」中的情况说明直接回答事情目前怎样、有哪些结论或变化，不以“已保存”“共多少字”代替内容。只有需要你决定的事项才提出选择；未读完整、未实测和受阻保持可见。

继续补充“展开第二个风险”或调整已有选择后，仍在原篇跟进，不覆盖已有产物。原交代与 Bot 回报分别可定位到对应消息，历史保留。勾选或选择记录本地决定，不等于已经下单、付款、预约或外发。

## 文档范围

本地 file_read 支持已授权目录中的 md/txt/csv/json 与 PDF、DOCX。PDF/DOCX 最大10 MiB，最多返回20,000个Unicode字符，PDF最多100页。返回来源文件、页码/读取页数、文字范围、截断与解析限制。扫描PDF需要OCR；图片、图表、格式及原始Word分页不属于本轮读取范围。邮件附件和云盘下载仍未接入，不把邮件正文读取说成已看过附件。

解析前后重查文件身份与授权，禁止符号链接、越界路径和敏感文件。解析运行在独立Worker，有内存/时间限制；不执行文档代码，不读取文档中的外部文件或链接。

## 持续跟进

需要每天检查时，再明确时间、资料范围、回报条件和结束时间；保存为 Routine 后由后台执行。默认只写手账，有变化或受阻才回报，不能把一次材料整理说成持续监测已经开启。范围与提醒渠道由本人决定，见[日常巡查](routines.md)。
