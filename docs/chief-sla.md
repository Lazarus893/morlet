# 小满可信处理与主动关注

2026-10-18。此文描述产品边界；部署与实机结果以实例验收记录为准。

## 状态先讲证据

`./scripts/pa.sh status`、`xiaoman_status`、Web 的「现在可以做什么」共用状态投影。是否能从微信交代，取决于当前/默认执行助手、微信通道和会话绑定；另一台助手在线不能替它亮绿灯。登录、会话工具、授权有效期分别核验。缺少证据显示黄灯，最近成功任务只在短时间内作为登录证据。超过时效显示“上次验证已超出时效”与上次验证时间，区别于从未验证及真正登录失效；不会为刷新状态周期调用模型。其他处理助手的限制收在独立展开层，不改变当前助手的判断。

历史执行与待处理问题分开：不会把旧失败或受阻改写成成功。后续执行只有在报告明确声明 `resolvesRunIds`、同会话、实际完成且原有全部手账事项有更高版本保存回执时，才关联为“原问题已接着处理”。只有同会话成功、只改同一事项，或没有事项 ID 的旧记录均不能自动关闭。主人可在 Web 任务追踪“接受当前结果，不再提示”，审计保存具体报告指纹与时间；这不会重试、取消任务或授权其他动作。执行仍在运行或结果未知时，必须先核对执行状态，不能收起限制来绕过。

长任务显示已有事实：排队、读取请求、资料返回、Agent 的进度报告、待批准或中断，以及已用时；不生成假百分比或宣称未发生的分析阶段。微信发“进度”或打开 Web 的任务追踪查看，只有一次收悉回复。

CLI 示例：`需要留意：暂不能确认微信任务可完整执行，交代与记录会保留。` 查看原因和待决定动作后再处理；不要把进程在、CLI 已安装或通道在线解释为任务已完成。

`status --verbose` 另列执行端、Mac 后台服务及失效路径的清理建议。它不会停止或删除服务。未提供有效期的授权明确标记未知；不是永久有效。

## 所有主动关注共用一个门

| 档位 | 行为 |
| --- | --- |
| Off | 只回应入站；不主动分析、触达 |
| Digest（默认） | 有候选才在摘要窗口合并；没有候选不调用模型 |
| Gentle | 到期事项、本人盯梢命中等可轻提醒，其余进摘要 |
| Active | 允许更积极的有依据跟进，仍遵守同一额度和写入审批 |

Web「提醒偏好」或微信「主动模式 Digest」可调整。旧的来源暂停、白名单、授权、静默和更严格的个人限制仍生效；切档不会恢复已暂停的来源。验证期额度到期恢复日常额度，编辑共享额度会明确结束验证期。

观察者、跟进文案分析和个人资料关注共用持久分析预算；空清单、静默、暂停在模型调用前拦截。候选用来源键幂等、规范化主题去重。主题合并是确定性键归并，并非声称能理解任意语义相似内容；生产者应使用稳定主题键。

主动发送先原子占额度，再在发出前重查静默、当前会话与来源。Digest 中每个来源都核验授权代次、账号指纹和有效期。改期、完成、取消、撤权或换账号不能沿用旧分析。发送结果未知保持未知，不自动重发；重启、切档不清计数。暂停或失效的旧候选可能被安全取消，不承诺补发过期事项。

正在对话的进度/审批属于该次交代的原路响应，不是新主动通道。长任务只发一次简短收悉；用户发「进度」可查，后台不定期刷「还在处理」。

## 批的是这一次生活动作

当前受控动作：取消共同待办、取消微信提醒、取消手账安排。预览显示具体事项、后果、有效期；审批绑定会话、执行租约、调用幂等键及完整参数指纹。版本或参数改变后重新确认。支持批准、拒绝、延后；没有可靠执行接口的动作允许「接受限制，继续整理」。

默认一次一批。限时授权、本会话授权尚未开放：现有原生回调不能保证批量授权只作用于同一组参数。批准后中断或不明结果不自动重放写入。

读资料、建计划、草稿与手账勾选可走受控工具。外发消息/邮件、下单、退订、任意文件修改及改权限目前没有完整的生活动作执行器，会被明确阻止。不能把 shell、手机或 `run_code` 当成绕过办法，也不能仅凭工具名获得授权。DSH 的生活会话使用原生受控工具与不可被插件放宽的执行闸；Codex 使用只读沙箱，原生权限扩展不会自动批准。

同一对话同一时刻只有一个处理 owner。等待审批、失联或取消尚未确认时，另一执行助手也不能抢同一对话；其他对话可以继续。确认停止后再接着处理，旧租约不能提交迟到结果。

## 验收口径

关注减少漏办、用户能安心授权、低价值消息进入摘要。测试覆盖四档、空清单零模型、跨入口额度、同主题归并、撤权/换账号、时间边界、参数变动、重复审批、原路回执和中断。隔离测试不代表真人微信或 iMessage 端到端验收；未接通的外发动作不能宣称已办理。
